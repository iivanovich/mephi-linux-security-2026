# MEPHI Linux Security Homework 2026

## Описание артефактов

В репозитории представлены результаты выполнения лабораторной работы по управлению привилегиями в GNU/Linux (Ред ОС). Ниже приведена таблица соответствия файлов разделам задания и проверяемым требованиям.

| Файл | Раздел | Что проверяется |
| --- | --- | --- |
| `history.out` | Все | Выполненные команды (логика решения и последовательность действий) |
| `stat.out` | 1, 3, 4 | Установка прав доступа на домашнюю директорию пользователя и утилиты (set-UID, права файлов) |
| `getcap.out` | 4 | Настройка привилегий (Linux capabilities: CAP_CHOWN) |
| `passwd` (копия /etc/passwd) | 1 | Управление пользователями (список пользователей, UID) |
| `group` (копия /etc/group) | 1 | Управление группами (состав групп, GID) |
| `sudoers_user1.out` | 5 | Настройка sudo (правило для пользователя user1) |
| `setuid_files.out` | 2 | Поиск файлов с установленным битом set-UID |
| `processes_euid0_ruid_normal.out` и `processes_during_passwd.out` | 2 | Мониторинг процессов (эффективный и реальный UID) |

## Краткое описание выполненных работ

### Раздел 1. Создание пользователя
- Создан пользователь `user1` с UID 1234.
- Пользователь добавлен в группу `students`.
- Настроена политика смены пароля.

### Раздел 2. Мониторинг файлов и процессов
- С помощью `find` найдены все файлы с битом set-UID.
- С помощью `ps` и `awk` выполнен мониторинг процессов: поиск процессов с euid=0 и ruid≠0. Демонстрация проведена в момент выполнения команды `passwd`.

### Раздел 3. Механизм set-UID
- Утилита `cat` скопирована в `~/lab_utils/cat_suid`.
- Установлен бит set-UID (`chmod u+s`).
- Продемонстрировано чтение защищённого файла `/etc/shadow` от имени обычного пользователя.

### Раздел 4. Механизм привилегий (Capabilities)
- Утилита `chown` скопирована в `~/lab_utils/chown_cap`.
- Добавлена capability `CAP_CHOWN` (`setcap cap_chown=ep`).
- Продемонстрирована смена владельца файла без прав root и без set-UID.

### Раздел 5. Настройка sudo
- В `/etc/sudoers` добавлено правило для `user1`, разрешающее изменение системного времени (через `date`/`timedatectl`).
- Правило сохранено в артефакте `sudoers_user1.out`.

### Раздел 6. Сбор артефактов и визуальное подтверждение
- Все необходимые файлы собраны в домашней директории пользователя `igor`.


---

**Примечание:** Файл `/etc/shadow` не загружался в репозиторий в целях безопасности. Проверка прав доступа к нему выполнена через утилиту `stat` (результат в `stat.out`) и демонстрацию чтения через set-UID утилиту.
